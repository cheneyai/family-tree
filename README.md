# 可穿透的家族瞬间 · 李登福支系

李登福房（六世至九世）家族记忆示意站：人际关系图谱 + 世代滤镜，点击人物（含配偶）查看「瞬间」占位。

## 预览

https://cheneyai.github.io/family-tree/

通行码见页面说明（浏览器本地门禁，非真正私有托管）。

## 本地打开

直接用浏览器打开 `index.html`，或任意静态服务器：

```bash
python3 -m http.server 8080
```

## 说明

- 纯静态：`index.html` + `app.js`
- 字体：Google Fonts（Noto Sans SC + DM Sans）
- 配偶为第一类人物卡片（头像字形 +「配偶」徽章），可点击查看瞬间
- 照片与短文为占位（素材稍后补），非正式谱牒
- Pages 无法提供服务端鉴权；通行码仅前端示意
